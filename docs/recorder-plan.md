# スタンドアロン録画デバイス — 要件定義（案）と構成候補

目標: PCなしで偽ころキャプチャの映像+音声を記録できる機器を作る。
**マイコン/ボードは未購入。要件確定後に選定する。**

## 大前提（提案）: 既存のnanoCH32V305はそのまま活かす

現行のnano+FWは「GBA→USBストリーム変換器」として完成している。録画デバイスは
**このUSBストリームを受けて保存する“ホスト”**を新設する構成が最小工数・最低リスク:

```
GBA → nanoCH32V305 (現行FWそのまま) → USBホスト機能を持つ録画ボード → microSD
```

ホスト側プロトコル処理のコード（GbaCapライブラリ、C#）はLinuxでもそのまま動くため、
Linux系ボードなら**ビューアの受信部を流用した録画アプリ**が短期間で作れる。

## 構成候補

### 案A: Raspberry Pi Zero 2 W（推奨候補）
- USBホスト(OTG) + クアッドコアA53 + **H.264ハードウェアエンコーダ**
- 240×160@60fpsのエンコードは余裕。MP4で保存すれば **約17GB/時 → 数百MB/時** に圧縮
- .NET 8がARM64/ARM32で動く → GbaCapライブラリ流用可
- 弱点: 起動に数十秒(Linux)、シャットダウン作法が要る(いきなり電源断はSD破損リスク)
- 概算部品: Pi Zero 2 W(~3,000円)、microSD 64GB(~1,000円)、USB OTGケーブル、
  電源(モバイルバッテリー可)、タクトスイッチ+LED(録画開始/停止表示)

### 案B: Teensy 4.1（ベアメタル、即起動）
- Cortex-M7 600MHz、**USBホスト(HS)ピン** + **SDIO接続microSD**を標準装備
- 生データ(4.7MB/s)をSDに直書き。即起動・即録画・電源断に強い(設計次第)
- 弱点: H.264エンコード不可 → **無圧縮で約17GB/時**（簡易圧縮を自作しても2-5倍程度）。
  録画後にPCで変換する運用になる。ホストスタックはArduino/Teensyduinoで開発（C++）
- 概算部品: Teensy 4.1(~5,000円)、microSD、USBホスト用ピンヘッダ配線、スイッチ+LED

### 案C: Raspberry Pi 4/5（据え置き・全部入り）
- 案Aの上位。**HDMI出力でプレビュー/大画面プレイしながら録画**も可能
- サイズ・消費電力・価格(1万円前後)が上がる

### 案D: (参考) UVC化を先にやる
- nanoのFWをUVC/UAC(標準カメラ/マイク)化すれば、市販の「UVC対応録画ガジェット」や
  スマホ(Android USBカメラアプリ)がそのまま録画デバイスになる。
  自作ハードは不要になるが、FW開発の難度は高め（UVC記述子+MJPEG圧縮 or 無圧縮UVC）

## 共通で必要になりそうな要素

- 録画開始/停止ボタン + 状態LED（録画中=赤点灯など）
- ファイル名用の時刻: RTCモジュール or 起動連番 or Wi-Fi時刻同期(Pi系)
- 電源: モバイルバッテリー(5V) を想定すると屋外でも使える
- ケース（3Dプリント or 市販ケース）

## ❓ 要件確定のための質問（回答ください）

1. **記録形式**: どちらを優先？
   - (a) MP4/H.264などの実用形式（そのままSNS投稿可、ファイル小）→ Pi系が必須
   - (b) 無劣化生データ（後からPCで変換、1時間で約17GB）→ Teensyでも可
2. **使用シーン**: 持ち歩いて外で録画する（電池駆動・小型重視）？ 家の机で使う（サイズ不問）？
3. **プレビュー**: 録画中に映像を確認したい？
   - (a) 不要（LEDだけでよい） (b) 小型液晶を付けたい (c) HDMIでテレビに出したい（=案C寄り）
4. **起動時間**: 電源を入れて数十秒待てる（Linux系OK）？ 即起動が必須（ベアメタル系）？
5. **録画時間の想定**: 1回あたり何時間くらい？（SD容量とファイル分割設計に影響）
6. **音声**: 映像と同じファイルに同録必須ですよね？（前提として進めてよいか確認）
7. **nanoの扱い**: 録画デバイス使用中はPCビューアと排他になるが問題ない？
   それとも「PCでも録画機でも挿し替えて使える」2WAY運用を想定？（→どちらでも対応可能だが確認）
8. **予算感**: 総額の目安（~5千円 / ~1万円 / こだわらない）
9. **将来のUVC化との優先順位**: 録画デバイスが先でよい？（案Dのように「UVC化してから
   汎用ガジェットに録らせる」ルートもあるため、方針確認）

回答が揃い次第、構成を1つに確定して部品リスト（購入リンク付き）と開発ステップを出します。

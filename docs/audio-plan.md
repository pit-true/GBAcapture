# 音声取得プラン

## GBAの音声経路（どこから取るべきか）

```
GBA CPU ──(L/R PWM音声出力)──> RCフィルタ ──> 音量ホイール ──> アンプU6 ──> スピーカ/ヘッドホン
              ↑ここが最も「デジタルに近い」          ↑ここ以降は音量ホイールの影響を受ける
```

GBAの音声はCPU内部で全チャンネル（PSG+Direct Sound）が**デジタルミックスされ、
PWM（1bit高速スイッチング）としてCPUのL/Rピンから出力**される。つまり
**CPUの音声出力ピンの時点が実質デジタル**で、そこから先は徐々にアナログ化していく。

## 推奨タップポイント: 「LOUT」「ROUT」ビア

GBA基板(AGB-CPU-02/03)の裏面、音声アンプ(U6)周辺に **LOUT / ROUT** と
シルク印字されたビアがある（CPU-03スキャンでは基板右下、R19/R20付近）。
これはCPUの音声出力（アンプ・音量ホイールより上流）で:

- **音量ホイールの位置に依存しない**一定レベルで取れる
- PWMキャリア（数十〜262kHz、ゲーム側設定による）が乗った波形
  → 高速サンプリングしてデジタルフィルタで落とすことで、
  アナログ経路の劣化を最小化した「ほぼデジタル」の取得ができる

※「U6-LIN / U6-RIN」印字のビアはアンプ入力（音量ホイール通過後）なので使わない。

## nanoCH32V305側の接続先

| GBA側 | nano側 | 理由 |
|---|---|---|
| LOUT | **PA4** | ADC IN4。ヘッダに出ており未使用（上段 A4） |
| ROUT | **PA5** | ADC IN5。同上（上段 A5） |
| (GND) | 接続済み (P1-GND) | 共通GND必須 — 映像用と共用でOK |

- PA4/PA5 はボード上段ヘッダの「A4」「A5」（写真 docs/photos/nanoCH32C305.jpg で確認済み）
- 直列に 1kΩ 程度を入れると安全（無くても実用上は動く見込み。GBA音声出力は
  低インピーダンス駆動、振幅は電源内 0〜VDD 範囲）

## FW側の実装方針（将来のM6）

1. TIM3等でADCを 96〜192kHz でトリガ、ADC1(PA4)/ADC2(PA5) をDMAで取り込み
   （デュアルADC同時サンプリング or 交互）
2. FWでデシメーション+ローパス（PWMキャリア除去）→ 32/48kHz PCM
3. 映像ラインパケットと同じUSBパイプに音声パケット（別マジック）を多重化
   → ビューアで WASAPI 再生。フレーム番号でリップシンク

## 参考

- GBA音声(PWM/Direct Sound)の仕様: GBATEK "GBA Sound Controller"
- SOUNDBIAS レジスタでPWM分解能/キャリアが変わる（ゲーム依存）ため、
  サンプリングは高め(≥96kHz)に取っておくのが安全

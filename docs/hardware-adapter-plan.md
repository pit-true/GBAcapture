# 専用基板・FFCアダプタの設計プラン（回路設計未経験者向けガイド）

目標: 手ハンダのジャンパ線を卒業し、**32ピン/40ピン両対応のタップ基板**を作って
GBAの電池ボックスに収める。

## 全体アーキテクチャ（推奨）

```
GBA基板 ──FFC──> [タップ基板] ──FFC──> (元のLCDへパススルー)
                     │
                     └─ nanoCH32V305 を基板上に直載せ (ピンヘッダ/ハンダ)
```

…ではなく、**今回の実績構成を活かした簡易案**を推奨:

```
[タップ基板] = 信号を「拾うだけ」の基板。LCDケーブルには触らない
  - GBA基板の裏面ビア(LDB1等のシルク付き)相当の信号を、基板上のテストパッド/
    スルーホールから引き出す設計は難しいため、
  - 実質は「nanoCH32V305 + コネクタ + 配線整理」を1枚にまとめたキャリア基板
```

### 現実的な3段階プラン

**段階1（半日・基板不要）: 配線の恒久化**
- 今のジャンパ線を**細いポリウレタン線(UEW, 0.2mm)** に置き換え、経路を短く均一に
- ホットボンドで応力止め。これだけでノイズ耐性と耐久性が大幅向上
- 電池ボックス収納は「nanoをカプトンテープで絶縁して電池室に固定」で達成可能

**段階2（初基板・難度低）: キャリア基板**
- nanoCH32V305 を載せる母艦基板。GBAへの19本は基板上の**1列コネクタ(JST-SH等)**に集約
- GBA側は今のハンダ付けのまま、コネクタで着脱可能に
- KiCad の題材として最適（部品2-3点、配線簡単）

**段階3（本命・難度中）: FFCインターポーザ**
- GBAのLCDコネクタとLCDケーブルの間に挟む**サンドイッチ基板**
  （市販の偽トロや gbaHD のアドオン基板と同方式）
- 32ピン(0.5mmピッチ)と40ピン(ピッチ要実測、おそらく0.5mm)の
  **両フットプリントを1枚に載せ**、使う側だけコネクタを実装する
- 40ピン↔32ピンは信号が+1シフトの関係（docs/gba-40pin-pinout.md）なので、
  基板パターンで両対応可能
- FFCコネクタは「スルー用（上下2個）+ タップ引き出し」構成

## 未経験者向けの進め方

1. **KiCad**（無料・定番）をインストール。「KiCad 入門」チュートリアル（Digi-Key の
   日本語動画シリーズが丁寧）を1周する
2. 回路図エディタで結線図を描く（今回のdocs/wiring.mdがそのまま回路図になる。
   受動部品すら不要 — コネクタとピンソケットだけ）
3. 基板エディタでアートワーク。電池室の寸法（実測: 単3×2の部屋）を
   Edge.Cuts（基板外形）に描いてサイズを守る
4. 製造は JLCPCB / PCBWay に garber を投げる（5枚で数百円+送料、納期1週間）
5. FFCコネクタの入手: 秋月/Digi-Key で「FFC/FPCコネクタ 0.5mm 40P」等。
   **フットプリント（ランドパターン）はデータシート通りに**（KiCadに既製ライブラリあり）

## 設計上の注意（今回の実測から得た知見）

- **GNDを最優先**: タップ基板でも信号線と同数レベルのGND接続を確保する
  （今回の全障害の原因はGND1本だった）
- 信号はハイインピーダンスで「見るだけ」: 直列に 100Ω 程度を入れると
  GBA側への影響とリンギングを抑えられる（無くても動くのは実証済み）
- GBAのロジックは約2.9V、CH32V305は3.3V耐圧 → レベル変換不要（実証済み）
- DCKは4.19MHz: 配線長は揃えて短く。FFCパススルー設計ではスタブを短く
- 将来のUVC化・録画デバイス化を見据えるなら、基板に音声2線（LOUT/ROUT→PA4/PA5）
  も最初から入れておく

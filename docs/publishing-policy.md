# 公開ポリシー — GitHubに置くもの / ローカル限定のもの

リポジトリは現在プライベートだが、**最終的に公開する前提**で以下のように区別する。

## GitHubに置いてよいもの（公開OK）

- ソースコード一式（firmware/, host/, .claude/）— 自作コード
- docs/ の技術文書（配線表、信号仕様、設計、手順書）— 自作文書
- 自分で撮影した**自分の機材・配線の写真**（権利は自分にある。公開判断は好みで）

## ローカル限定（絶対にpublicに含めない）

| 対象 | 理由 | 現状 |
|---|---|---|
| `docs/photos/GAME_BOY_ADVANCE_*_PCB_SCAN_*.jpg` | **第三者が作成したPCBスキャン**（ネット入手・再配布権なし） | 追跡解除済み(2026-07-06)。**公開前に履歴からも除去必須** |
| `docs/captures/`・ルートの `capture*.png` 等 | **ゲーム画面 = 任天堂/ゲームフリークの著作物** | 公開前に除去（下記参照） |
| ルートの作業用スクショ (`eizou_hen*`, `kadomaru*` 等) | 作業用一時ファイル | 追跡解除済み・以後gitignore |
| `tools/` | 外部バイナリ（wchisp, GCC, 回路図PDF等） | 元々gitignore |

## ⚠️ 公開前に必ずやること（履歴の浄化）

一度コミットしたファイルは **削除しても履歴に残る**。公開時は次のどちらかを行う:

1. **新規リポジトリに現行スナップショットだけを積み直す**（最も簡単・確実）
2. `git filter-repo` で該当パスを全履歴から除去する

除去対象（履歴に存在するもの）:
- `docs/photos/GAME_BOY_ADVANCE_*`（第三者PCBスキャン）
- `docs/captures/*.png`, `capture01.png`, `eizou_hen*.png` 等（ゲーム画面）
- README.md のゲーム画面埋め込み → 公開版では自分の機材写真か図に差し替える

## 運用ルール（今後）

- 作業用スクショ・キャプチャ画像はリポジトリ**ルート直下**に置く（gitignore済み）
- 第三者の資料（スキャン・データシート等）は `tools/` か `docs/photos/` に置く（gitignore済み）
- コミット前に `git status` で画像の混入がないか一瞥する
